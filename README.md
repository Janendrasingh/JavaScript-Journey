## 💻 How to Run the Code

Most basic JavaScript examples can be executed using a web browser or Node.js.

### Option 1: Using a Web Browser

1. Open your project in VS Code.
2. Create an HTML file.
3. Add a JavaScript file using a `<script>` tag.
4. Open the HTML file in a browser.
5. Open Developer Tools and check the Console.

Example:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript Practice</title>
</head>
<body>
    <h1>JavaScript Journey</h1>

    <script src="script.js"></script>
</body>
</html>
```

Create `script.js`:

```javascript
const message = "Hello, JavaScript!";

console.log(message);
```

### Option 2: Using Node.js

Install Node.js, open the terminal, and run:

```bash
node script.js
```

This approach is useful for practicing JavaScript fundamentals without creating an HTML page.

*Note: Browser-specific APIs such as `document` and `window` are not available in a standard Node.js environment.*
