# BMI Calculator 🧮

A simple and responsive **BMI (Body Mass Index) Calculator** built using HTML and CSS, inspired by the JavaScript DOM projects from Chai aur Code.

This project provides a basic interface for entering height and weight, viewing BMI weight categories, and learning how to structure and style a web application.

## 📌 About the Project

The BMI Calculator is a beginner-friendly frontend project designed to practice HTML form elements, CSS styling, element selection, and webpage layout.

The interface includes:

* Input fields for height in centimeters (CM).
* Input fields for weight in kilograms (KG).
* A Calculate button.
* A section to display the BMI result.
* A BMI weight guide showing different weight categories.

**Note:** The current HTML and CSS implementation provides the user interface only. JavaScript must be added to calculate and display the actual BMI.

## 🧮 BMI Formula

Body Mass Index (BMI) is calculated using the following formula:

$$
BMI = \frac{Weight\ (kg)}{Height\ (m)^2}
$$

**Example:**

* Weight: 70 kg
* Height: 1.75 m

Calculation:

```text
BMI = 70 / (1.75 × 1.75)
BMI = 22.86
```

## 📊 BMI Weight Guide

The interface uses the following categories:

| BMI Range  | Category     |
| ---------- | ------------ |
| Below 18.6 | Underweight  |
| 18.6–24.9  | Normal range |
| Above 24.9 | Overweight   |

These are the ranges displayed in this project; BMI interpretation can vary by population and clinical guidelines.
