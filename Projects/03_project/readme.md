# 🕒 Digital Clock

A simple **Digital Clock Web Application** built using HTML, CSS, and JavaScript. This project displays the user's local time in a digital format and updates automatically every second.

This project is part of my JavaScript learning journey, where I am practicing DOM manipulation and working with JavaScript's Date object.

## 🚀 Features

* 🕒 Displays the user's current local time.
* 🔄 Updates the clock every second.
* 🎨 Simple and clean user interface.
* 📱 Basic responsive layout.
* 🧩 Demonstrates JavaScript DOM manipulation.
* ⏰ Uses the JavaScript `Date` object to retrieve the current time.

## 🛠️ Technologies Used

* **HTML5** — Structures the webpage.
* **CSS3** — Styles the clock and webpage layout.
* **JavaScript** — Retrieves and updates the current time dynamically.

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder:

   ```bash
   cd Digital-Clock
   ```

3. Make sure `index.html`, `style.css`, and `script.js` are in the same directory.

4. Open `index.html` in your web browser.

5. The digital clock will display the current local time.

**Tip:** You can use the Live Server extension in Visual Studio Code to run the project.

## 🧠 Concepts Practiced

Through this project, I am practicing the following JavaScript concepts:

* DOM selection using `document.getElementById()`.
* Updating HTML elements using `innerHTML` or `textContent`.
* Working with the JavaScript `Date` object.
* Extracting hours, minutes, and seconds.
* Using `setInterval()` to update the clock every second.
* Connecting HTML, CSS, and JavaScript.
