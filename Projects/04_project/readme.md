# 🎯 Guess the Number Game

A simple and interactive **Guess the Number Game** built using HTML, CSS, and JavaScript. This project is part of my JavaScript learning journey, where I am practicing DOM manipulation and JavaScript event handling.

## 📌 About the Project

The Guess the Number Game is a beginner-friendly web project in which the player tries to guess a randomly generated number between **1 and 100**.

The player gets **10 attempts** to guess the correct number. After every guess, the game provides feedback to help the player determine whether the guess is too high or too low.

This project helps me understand how HTML, CSS, and JavaScript work together to create an interactive web application.

## ✨ Features

* 🎲 Guess a random number between 1 and 100.
* 🔢 Maximum of 10 attempts to guess the correct number.
* 📋 Display previously entered guesses.
* 🔄 Show the number of attempts remaining.
* 💡 Provide feedback when a guess is too high or too low.
* 🏆 Display the result when the player wins or loses.
* 🎨 Simple and beginner-friendly user interface.

*Note: These are the intended game features; they require the JavaScript implementation to work.*

## 🛠️ Technologies Used

* **HTML5** — Creates the structure of the game.
* **CSS3** — Styles the interface and improves its appearance.
* **JavaScript** — Implements the game logic, handles user input, and manipulates the DOM.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Guess-The-Number
   ```

3. Open the `index.html` file in your browser.

4. Enter a number between 1 and 100.

5. Click **Submit guess** to check your answer.

6. Continue guessing based on the feedback until you win or run out of attempts.
