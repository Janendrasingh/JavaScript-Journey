# 🎨 Color Scheme Switcher

A simple and beginner-friendly web development project inspired by the **JavaScript DOM Manipulation** series by Chai aur Code.

The project displays different color options that users can click to change the background color of a webpage. It is designed to practice HTML structure, CSS styling, and JavaScript DOM manipulation.

## 📌 Project Overview

The Color Scheme Switcher is a small interactive web application that demonstrates how JavaScript can manipulate HTML elements and modify webpage styles dynamically.

Users can select a color from the available options to change the background color of the webpage.

## ✨ Features

* 🎨 Four color options: Grey, White, Blue, and Yellow.
* 🖱️ Clickable color boxes.
* 🧩 Simple and beginner-friendly user interface.
* 📱 Basic responsive layout.
* 💻 Practice with HTML, CSS, and JavaScript DOM manipulation.

> **Current Status:** The HTML and CSS structure is implemented. JavaScript functionality for changing the background color is yet to be added.

## 🛠️ Technologies Used

* **HTML5** — Creates the webpage structure.
* **CSS3** — Styles the webpage and color boxes.
* **JavaScript** — Will be used to handle click events and change the background color dynamically.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Navigate to the Project Directory

```bash
cd Color-Scheme-Switcher
```

### 3. Open the Project

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

## 🧠 Concepts Practiced

This project helps you understand the following web development concepts:

### HTML

* HTML document structure.
* Headings and navigation links.
* `div` and `span` elements.
* Classes and IDs.
* Linking external CSS files.

### CSS

* Background colors and text styling.
* Margins and padding.
* Flexbox.
* Element selectors, class selectors, and ID selectors.
* Hover effects.
* Cursor styling.

### JavaScript — Planned Implementation

* DOM selection using `querySelector()` and `querySelectorAll()`.
* Event handling using `addEventListener()`.
* Changing CSS properties using JavaScript.
* Working with HTML elements and their IDs.
