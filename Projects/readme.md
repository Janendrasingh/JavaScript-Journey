# JavaScript Mini Projects 🚀

This repository contains four beginner-friendly projects built using **HTML, CSS, and JavaScript**. These projects helped me practise JavaScript fundamentals, DOM manipulation, event handling, functions, conditional statements, and working with user input.

The main goal of this repository is to strengthen my JavaScript skills through practical, hands-on projects.

## 📂 Projects Included

### 1. 🎨 Colour Scheme Switcher

**Folder:** `P1-Colour-Scheme-Switcher`

A simple interactive web application that allows users to change the background colour of a webpage by clicking different colour buttons.

**Features:**

* Switch between different background colours.
* Handle button click events using JavaScript.
* Dynamically update webpage styles using DOM manipulation.

**Concepts Learned:** DOM manipulation, event handling, `querySelector()`, `addEventListener()`, and CSS styling through JavaScript.

---

### 2. ⚖️ BMI Calculator

**Folder:** `P2-BMI-Calculator`

A BMI (Body Mass Index) calculator that calculates a user's BMI based on their height and weight.

**Features:**

* Accept height and weight as user input.
* Calculate BMI using the standard formula.
* Validate user input before performing calculations.
* Display the calculated BMI and its general category.

**Concepts Learned:** Form handling, input validation, `parseFloat()`, conditional statements (`if...else`), mathematical operations, and DOM manipulation.

**BMI Formula:**

$$
BMI = \frac{\text{Weight (kg)}}{\text{Height (m)}^2}
$$

---

### 3. 🕒 Clock Display

**Folder:** `P3-Clock-Display`

A digital clock that displays the current time and updates automatically.

**Features:**

* Display the current time.
* Update the clock automatically at regular intervals.
* Present time dynamically on the webpage.

**Concepts Learned:** JavaScript `Date` object, `setInterval()`, DOM manipulation, functions, and dynamic content updates.

---

### 4. 🎯 Guess the Number Game

**Folder:** `P4-Guess-the-Number-Game`

An interactive number-guessing game in which the player tries to guess a randomly generated number within a specified range.

**Features:**

* Generate a random number.
* Accept guesses from the player.
* Provide feedback on whether a guess is too high or too low.
* Track attempts and help the player reach the correct answer.

**Concepts Learned:** `Math.random()`, `Math.floor()`, event handling, conditional statements, loops or repeated user interactions, and input validation.

---

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the repository folder in VS Code or your preferred code editor.

3. Navigate to the project folder you want to run.

4. Open its HTML file in your browser, or use the **Live Server** extension in VS Code.

5. Interact with the webpage and explore the JavaScript functionality.
